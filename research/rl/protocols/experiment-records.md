# 实验记录与清理约定

正式运行保存 EvoWorld commit、RLinf commit、完整解析配置、环境版本、基础权重来源和校验值、观测/动作定义、训练与评测种子、任务集与回合时限。正式结果对应已提交代码；不得静默带入未记录修改。

训练与独立评测分开记录。算法比较至少报告成功率、环境交互步数、参数更新次数、实际耗时与显存；保留每任务结果，不能只比较总平均。当前 LIBERO 历史评测的来源文件和路径按原样保留，不能将迁移后的 commit 冒充当时运行版本。

正式 run 包含 config、metrics、logs、videos、provenance，训练时另设 checkpoints。日志和结果不入 Git，精简报告可提交。正式检查点保留策略在每次训练配置中明确，未约定前不自动删除。

临时测试必须位于 scratch，自动清理要求验收成功、归属标记匹配和目录边界检查。禁止从整个 outputs 或共享模型目录递归清理。历史 SAGE/DSRL 实验保留原处，本次仅整理 LIBERO 新研究线。
